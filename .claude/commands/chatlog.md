# ChatGPT会話ログ保存

ミナとの会話まとめを受け取り、Obsidianで読めるMarkdownファイルとして保存してください。

## 保存先

`docs/chatgpt-log/YYYY-MM-DD_会話テーマ.md`

会話テーマは、内容を短い日本語で表してください。

## やること

1. こうじに「ミナのObsidian用まとめを貼ってください」と伝える
2. 貼られた内容を読み取る
3. `docs/chatgpt-log/` にMarkdownファイルとして保存する
4. 保存後、ファイル名をこうじに伝える

## 保存する内容

貼られたMarkdown本文を、基本的にそのまま保存してください。

ただし、以下だけ整えてください。

- タイトルがなければ先頭にタイトルをつける
- 日付がなければ今日の日付を入れる
- ファイル名に使えない記号は避ける
- 内容を勝手に短くしすぎない
- こうじの確信、ミナの反証、その後の着地がある場合は分けて残す
- 未解決点や揺らぎは削らない

## 注意

- `.env.local` は絶対に触らない
- `app/` や `api/` などアプリ本体のコードは触らない
- 保存先は `docs/chatgpt-log/` の中だけにする
- 保存後に `git status` を確認する
