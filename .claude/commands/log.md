# 作業ログ作成

ここまでのClaude Code作業を、あとから読み返せる作業ログとしてまとめてください。

保存先：
docs/claude-code-log/YYYY-MM-DD_作業内容.md

作業ログを作る前に、以下を確認してください。
- git status
- git diff --stat
- 重要な変更がある場合は git diff の要点

ログには、以下を入れてください。

## 結論
今回できたことを1〜3行で書く。

## こうじがやろうとしていたこと
技術ではなく、目的を書く。

## Claude Codeが行ったこと
実際の作業を書く。

## 変更したファイル
変更したファイルと内容を書く。

## 判断理由
なぜその変更にしたのかを書く。

## うまくいったこと
確認できたことを書く。

## 失敗・未確認のこと
失敗、未確認、不安点を書く。

## git status
現在の状態を、こうじが読める言葉で説明する。

## git diff の要点
細かいコードではなく、何が変わったかを書く。

## 次にやること
次に確認・修正することを書く。

## ミナ・エリス・Claude Codeへ渡す用
次の会話でそのまま貼れる短い引き継ぎ文を書く。

書き方：
- 難しい技術表現は避ける
- 事実と推測を分ける
- 未確認は未確認と書く
- 作業を美化しない
- あとから読んで再開できるようにする
